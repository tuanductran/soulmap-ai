# Security Policy

If you discover a security issue, please do not open a public issue.

## Reporting

- Prefer a private report (email or private message) to the repository owner.
- Include reproduction steps, impact, and any suggested fixes.

## Scope

This repository contains content and local scripts. There are no deployed services by
default, but issues like prompt injection vectors, unsafe subprocess invocation, or
mishandling user-provided data are still in scope.
