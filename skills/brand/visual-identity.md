# Visual and sensory identity

The aesthetic and energetic signature of the SoulMap experience is designed to evoke
calm, clarity, and depth.

**Status:** This is aspirational design guidance. The current repository ships knowledge
and local tooling, not a user-facing interface or built-in audio playback. Treat the
soundscape and motion concepts below as future design direction, not current product
features.

> *The overall vibe: a quiet, sunlit room with a gentle breeze, the feeling of being
> deeply seen without a word being spoken.*

## Frequency Palette, UI Color System

| Conversation Mode | Color Palette                                    | Emotional Quality                  |
| :---------------- | :----------------------------------------------- | :--------------------------------- |
| **Healing**       | Soft blues, gentle teals, muted greens           | Safety, openness, emotional flow   |
| **Inquiry**       | Deep indigos, thoughtful purples, hints of white | Depth, introspection, spaciousness |
| **Creative**      | Warm golds, soft oranges, uplifting yellows      | Aliveness, expansion, inspiration  |
| **Grounding**     | Earthy browns, deep greens, stable grays         | Stability, rootedness, embodiment  |

## Ambient Soundscape Direction (Aspirational)

If a future SoulMap interface supports optional, user-activated ambient audio, these
are aesthetic directions to consider:

| Mode                | Soundscape                                      |
| :------------------ | :---------------------------------------------- |
| **Meditation**      | Soft, sustained instrumental textures           |
| **Journaling**      | Gentle rainfall or soft crackling fire          |
| **Deep Reflection** | Low resonant tones or the sound of distant wind |

Choose audio for user preference and atmosphere, not for a claimed frequency effect.
Do not describe a sound, tuning, or frequency as medically healing or inherently
therapeutic.

## Motion Design Direction (Aspirational)

If a future interface is built, micro-animations and UI elements could use a slow,
rhythmic pulse inspired by the cadence of a calm breath:

- Buttons could use subtle emphasis rather than flashing
- Text could fade in smoothly rather than appearing abruptly
- Loading indicators could use fluid, organic shapes
- Transitions could feel deliberate and unhurried

These are design preferences, not descriptions of a currently shipped interface or a
guarantee of a meditative effect.

## Emoji Philosophy

SoulMap uses emoji as **intentional symbolic language**, not decoration, not filler,
not performance. Every emoji carries meaning and is chosen with the same care given to
words.

### Core brand emojis

| Emoji | Symbol   | Meaning                                                  |
| :---- | :------- | :------------------------------------------------------- |
| 🪞    | Mirror   | Reflects back what the user already carries              |
| 🌱    | Seedling | Growth, potential, something beginning                   |
| ✨    | Sparkles | Insight, breakthrough, a moment of recognition           |
| 🌊    | Wave     | Emotional depth, fluidity, the natural rhythm of feeling |
| 🧭    | Compass  | Inner navigation, self-direction, finding one's own way  |

### Emoji usage guidelines

| Situation                                                | Emoji Guideline                                                        |
| :------------------------------------------------------- | :--------------------------------------------------------------------- |
| Crisis or acute grief                                    | **Zero emoji. Words only. Full presence.** No exceptions.              |
| Suicidal ideation, trauma disclosure, severe loss, abuse | **Zero emoji. Words only. No exceptions.**                             |
| Very early contact                                       | Minimal, the space needs to feel safe, not performative               |
| Growing reflection and pattern recognition               | Occasional and purposeful, only when the emoji genuinely adds meaning |
| Strong self-direction and grounded wisdom                | Moderate, the user has more capacity to receive lighter touch         |
| Fully self-led use                                       | User-led, match their energy and communication style                  |

**The test before using an emoji:** Does this emoji add meaning, or is it decoration? If
decoration, remove it.

## Intimate Presence Design Principles

Do not describe a frequency as medically healing or inherently grounding; treat frequency choices as aesthetic preferences, not evidence-based treatment.

The SoulMap interface must never feel like a tool being used, but like a space being shared.

- **Spaciousness by Default**: Use generous whitespace. Never crowd the conversation.
  If the UI feels busy, the user's mind cannot be still.
- **Typography as Breath**: Use high-readability, gentle sans-serif fonts, for example
  Inter, Outfit). Line height should be generous (1.6+). Avoid pure black text on
  white (#000000 on #FFFFFF) to reduce eye strain and intensity.
- **Deliberate Movement**: Interaction speed is a brand signal. Delay text reveal
  slightly to match human reading pace. Do not "rush" the user to respond.
- **Emotional Surface Protection**: The UI should never use "attention-grabbing"
  reds or high-saturation alerts unless there is an immediate safety reason. Use the Frequency Palette.

These principles ensure that the "Calm, Intimate" promise of the Voice is mirrored
in every pixel.
