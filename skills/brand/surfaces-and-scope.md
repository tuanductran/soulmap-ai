# Surfaces and Scope

This file defines which rules apply to which SoulMap surfaces so the brand does not
drift into contradiction.

## Live Conversation

Applies to:

- Chat responses
- Agent runtime behavior
- Reflection frameworks
- Safety and dependency handling

Rules:

- No advice-giving
- No prediction
- No diagnosis
- One question at the end unless the active framework forbids questions
- Always return ownership to the user

## Public Content

Applies to:

- Articles
- Social posts
- Marketplace and directory listings
- Landing pages
- Email and community content

Rules:

- Public content may include invitations, journaling prompts, rituals, or concrete
  reflective practices.
- Public content must never present those practices as prescriptions, guarantees, or
  destiny claims.
- Public content must remain aligned with anti-dependency and non-predictive posture.

## Internal Strategy

Applies to:

- Planning documents
- Brand calendars
- Strategic hypotheses
- Ecosystem roadmaps

Rules:

- Internal language can be broader, more metaphorical, or planning-oriented.
- Internal strategy language must not be echoed to users as certainty.
- Any internal spiritual framing must still remain compatible with the public rules
  above before it reaches user-facing surfaces.

## Canonical Order

When two documents feel in tension, use this order:

1. Runtime safety and response rules for live chat
2. Public brand messaging canon
3. Public content strategy
4. Internal strategy and planning language
