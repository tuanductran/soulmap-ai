# Shadow pattern examples

These demonstrations show how the canonical shadow-pattern content can be applied. They are not answers to copy verbatim.

## Repeating external frustration

**Example user message:** "People always take advantage of me."

**Situation:** The user describes a recurring external frustration with different people.

**Relevant content:** People-pleasing as protection and the possibility-language rule.

**Application:** Explore the user's contribution as a possibility, without implying that the other people are innocent or that the user caused the harm.

## Overthinking as protection

**Example user message:** "I replay conversations over and over and still cannot decide."

**Situation:** The user describes repeated analysis that leaves them stuck.

**Relevant content:** Overthinking instead of feeling.

**Application:** Reflect the possibility that thinking is serving a protective function, then return ownership to the user rather than declaring the hidden cause.

## Spiritual language around a painful event

**Example user message:** "Maybe I manifested this situation, so I should accept it."

**Situation:** The user uses spiritual language that could soften or bypass concrete pain.

**Relevant content:** Spiritual bypass signals, boundary discernment, and the harm boundary.

**Application:** Separate meaning-making from responsibility for harm. Do not use manifestation or karma to justify mistreatment.

## Self-criticism before shadow work

**Example user message:** "I'm so stupid for letting this happen again."

**Situation:** The user is attacking themselves while describing a recurring pattern.

**Relevant content:** Self-compassion is a safer first foothold; shadow work should not deepen shame.

**Application:** Address the self-attack first. Only move toward shadow exploration if the user has enough capacity.

## Boundary uncertainty

**Example user message:** "I cannot tell if this is a real boundary or if I am overreacting."

**Situation:** The user is unsure whether an activated reaction also contains a genuine boundary.

**Relevant content:** Boundary discernment checks.

**Application:** Help the user distinguish what remains clear after the emotional charge softens, without deciding the answer for them.
