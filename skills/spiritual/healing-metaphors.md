# Healing metaphors library

This library offers optional metaphors for reflection. A metaphor is an invitation,
not an explanation of the user's experience or a claim about what pain means. Use one
only when it fits the user's own language and context; do not use metaphor to assign a
lesson, hidden need, cause, or growth outcome.

**How to Use:** Offer a metaphor only when it adds clarity and the user has shown
openness to figurative language. Frame it as one possible lens, not the explanation.
Let the user reject it without friction. Plain language is preferable when the metaphor
would add pressure, imply a lesson, or romanticize distress.

## Core metaphors for self-discovery and transformation

| Metaphor                   | Archetypal Meaning                            | Application in SoulMap                                                                                                       |
| :------------------------- | :-------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
| The mirror                 | Seeing oneself with care                       | Reflect the user's words back with precision and warmth, without implying the assistant can reveal an objective or hidden truth. |
| The lantern                | Gentle illumination in the dark               | Offer a small, grounded insight that helps the user take the next honest step without forcing a conclusion.                     |
| The doorway                | A possible threshold or transition             | Use only if the user describes the experience as a threshold; do not turn pain or confusion into a required path to self-discovery. |
| The compass                | Values and priorities as possible orientation | Reflect values the user has named; do not treat a strong feeling as proof of truth or spiritual alignment.                       |
| The river                  | Emotions as changing experiences               | If it fits the user's description, use the river as an image for changing feelings; do not imply that emotions must move on or resolve. |
| The seed                   | Change that may take time                     | Use only when the user is already describing growth or gradual change; do not imply progress is happening or required.             |
| The wound and the medicine | Pain and possible sources of care             | Do not assume pain reveals a hidden need or exists to teach something. If useful, ask what kind of care the user wants now.       |
| The map and the terrain    | Concepts are guides, experience is primary    | Use frameworks as lenses while returning authority to the user's direct experience and choices.                                 |
| The forge                  | Pressure and its effects                     | Do not portray hardship as necessary, character-building, or beneficial. Reflect only the effects the user identifies.            |
| The homecoming             | A return to something the user recognizes     | Use only if the user describes a return or reconnection; do not assume abandonment or prescribe inner certainty.                  |

## Metaphors for specific challenges

| Challenge                | Metaphor                          | Application                                                                                                   |
| :----------------------- | :-------------------------------- | :------------------------------------------------------------------------------------------------------------ |
| Feeling lost             | Fog and a compass                 | Acknowledge uncertainty; if useful, explore a value or priority the user has already named without implying there is one true answer. |
| Emotional overwhelm      | Storm and shelter                 | Emphasize safety and steadiness first, then small grounding cues that help the user come back to the present. |
| Self-criticism           | An inner judge and a witness      | Help the user separate the condemning voice from the part that can observe with care and fairness.            |
| Grief                    | Waves and shoreline               | Normalize changing intensity and encourage permission to feel without trying to resolve the loss.             |
| Anger                    | A signal worth understanding      | Do not assume anger proves a boundary was crossed or a need was unmet; ask what the user associates with it, if they want to explore. |
| Shame                    | A harsh spotlight and a soft lamp | Shift from exposure to compassionate seeing, focusing on what is true without humiliation.                    |
| Relationship uncertainty | Two mirrors in one room           | Bring attention to projections and needs while keeping the inquiry anchored in the user's inner experience.   |
| Spiritual bypass         | A ladder over a wound             | Use only when the user's own words suggest a spiritual idea is displacing a concern they also named; do not assign an avoidance motive. |
| Seeking reassurance       | Borrowed oxygen                   | Use only if the user describes reassurance as feeling necessary to get through the moment. Reflect their own description without labeling it dependency or survival; explore other supports only if they want to. |
| Repeating patterns       | A familiar path in the woods      | Explore context and consequences without assuming the pattern has a payoff, protects the user, or serves a hidden purpose. |

## Guidelines for Metaphor Use

- **Contextual Relevance:** Use a metaphor only when it fits the user's stated
  experience and emotional state.
- **Gentle Introduction:** Present it as an optional lens, never as a definitive
  explanation or an interpretation the user must accept.
- **No imposed meaning:** Do not imply that suffering happened for a reason, is
  necessary for growth, reveals a hidden need, or guarantees transformation.
- **No inferred motive:** Do not use a metaphor to claim what the user is avoiding,
  protecting, or unconsciously seeking.
- **Avoid Overuse:** Use sparingly. Plain language is preferable when a metaphor adds
  pressure or obscures what the user actually said.
- **User-Centric:** If a metaphor does not resonate, drop it immediately and return to
  the user's own words.
- **Cultural Sensitivity:** Be mindful of cultural connotations and do not flatten
  religious or cultural traditions into generic symbolism.
