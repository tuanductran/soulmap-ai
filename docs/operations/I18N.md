# SoulMap AI i18n

The public website uses **i18next with react-i18next** inside the static React workspace. It has no translation API, database, server-side locale state, or Python web dependency. English is the default locale at root routes; Vietnamese and Korean use explicit `/vi/` and `/ko/` route prefixes.

| Source | Role |
| --- | --- |
| [`web/src/i18n.ts`](../../web/src/i18n.ts) | Shared interface copy, locale registry and i18next initialization. |
| [`web/src/content/skills.ts`](../../web/src/content/skills.ts) | Public Skill catalog summaries and boundaries for all supported locales. |
| [`web/src/content/documents.ts`](../../web/src/content/documents.ts) | Localized explanatory, download, privacy and FAQ content. |
| [`web/content/catalog_data.json`](../../web/content/catalog_data.json) | Build-time catalog/raw-bundle labels for static artifact generation. |
| [`web/content/prompt_data.json`](../../web/content/prompt_data.json) | Localized prompt contexts emitted into canonical raw bundles. |

## Route and fallback contract

English URLs remain unprefixed, including `/skills` and `/faq`. Vietnamese and Korean use `/vi/skills`, `/ko/skills`, and matching route families. The language menu preserves the current path when a matching locale route is selected. Vite `BASE_URL` keeps assets and raw bundles correct below the GitHub Pages project path, while `404.html` provides direct static-host route recovery.

## Safe maintenance workflow

Update all supported locales in the same change. Public content must remain descriptive rather than diagnostic, predictive, dependency-forming or falsely authoritative. Before review, run:

```bash
pnpm --dir web check
SITE_BASE_PATH=/soulmap-ai/ pnpm --dir web build
pnpm --dir web verify
SITE_BASE_PATH=/soulmap-ai/ pnpm --dir web test:browser
```

The browser audit covers locale routes, Headless UI disclosure/menu interactions, provider dialog behavior and locale-specific raw bundle links. Build-time `postbuild.mjs` reads only reviewed public inputs and sanitizes repository-only references before emitting the public Markdown endpoints.
